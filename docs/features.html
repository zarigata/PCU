Features

Everything you need to build your voxel world

🎮 High-Performance Voxel Engine

Efficient chunked world generation with level-of-detail rendering. Our engine handles massive worlds with smooth framerates.

  • Chunk-based world storage
  • Frustum culling and occlusion
  • Greedy meshing for performance
  • Procedural terrain generation
  • Real-time lighting and shadows
🗺️

⚡ Vulkan Rendering

Modern graphics API for maximum performance across all platforms. Take advantage of today's GPU capabilities.

  • Vulkan 1.2+ rendering backend
  • Compute shaders for terrain
  • Multi-threaded command buffers
  • Descriptor indexing for bindless
  • Ray tracing ready architecture
⚡

🔧 Built-in Modding API

Create custom blocks, items, entities, and game mechanics without modifying the engine core.

  • Lua scripting support
  • Custom block registration
  • Item and recipe system
  • Event-driven architecture
  • Hot-reload during development
🔧

🌐 Multiplayer Ready

Built from the ground up for multiplayer. Host your own server or join public servers.

  • Client-server architecture
  • Authoritative server model
  • Chunk synchronization
  • Player authentication
  • Dedicated server binary
🌐

🎨 Asset Pipeline

Import your own textures, models, and sounds. Full support for custom content.

  • Texture pack support
  • 3D model importing
  • Audio system with spatial sound
  • Hot-swappable assets
  • Resource pack system
🎨
