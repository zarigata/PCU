Features

Everything you'd expect from a top-tier voxel game — and then some. All free, all open source.

🌍 World & Exploration

🏔️

Infinite Procedural Worlds

Every world is unique. Multi-octave noise generation creates realistic terrain that stretches to the horizon and beyond.

  • 60+ biome types
  • Smooth biome blending
  • Oceans & rivers
  • Mountains & valleys
🕳️

Caves & Underground

3D noise-carved cave systems, ravines, underground lakes, and lava flows. The underground is as rich as the surface.

  • 3D cave carving
  • Ravines
  • Underground lakes
  • Lava caverns
🏰

Generated Structures

Discover villages, temples, dungeons, strongholds, mineshafts, ocean monuments, and more scattered across the world.

  • Villages
  • Strongholds
  • Temples
  • Dungeons & spawners
  • Ocean monuments
🌀

Three Dimensions

Overworld, Nether, and End — each a fully realized dimension with unique terrain, blocks, and gameplay.

  • Overworld
  • Nether (5 biomes)
  • End (outer islands)
  • Custom dimensions via mods

⚔️ Gameplay

🔨

Crafting & Survival

Full survival loop: mine resources, craft tools and armor, build shelter, farm food, and explore. Shaped and shapeless recipes, smelting, and more.

  • 200+ blocks
  • 50+ items
  • Shaped/shapeless recipes
  • Smelting
🎒

Inventory & Equipment

Full inventory system with armor slots, offhand, and drag-and-drop management. Quick-bar for fast access.

  • 36-slot inventory
  • Armor slots
  • Offhand
  • Hotbar
🏆

Achievements & Stats

Track your progress with an advancement system and detailed player statistics. See how far you've come.

  • Advancement tree
  • Playtime tracking
  • Block/item stats
  • Distance traveled
👾

Mobs & Entities

Hostile and passive creatures. Animals, monsters, and NPCs with AI behaviors, pathfinding, and drops.

  • Passive mobs
  • Hostile mobs
  • AI behaviors
  • Loot drops

🧩 Modding

📜

Lua Scripting

Write mods in Lua — create blocks, items, entities, dimensions, and game mechanics. Simple, powerful, and hot-reloadable.

  • Lua 5.4
  • Full game API
  • Hot reload
  • Sandboxed per mod
🔧

Native C++ Plugins

Need maximum performance? Write native C++ plugins with full engine access. Same API, zero overhead.

  • C++20
  • Full engine access
  • Direct memory
  • Plugin system
🎨

Resource Packs

Replace any texture, model, sound, or shader. Install community packs or create your own. Full customization.

  • Custom textures
  • Custom models
  • Custom sounds
  • Custom shaders

⚡ Performance & Tech

🖥️

Vulkan Rendering

Modern graphics API for butter-smooth performance. Multi-threaded rendering, cascade shadows, bloom, FXAA, and color grading.

  • Vulkan 1.3
  • 60+ FPS
  • Cascade shadows
  • Bloom & FXAA
🌐

Multiplayer

Join friends or host your own server. ENet-powered networking with low latency, packet compression, and reliable delivery.

  • Dedicated server
  • Low latency
  • Packet compression
  • Self-hosted
🔊

Immersive Audio

Full positional audio with reverb, occlusion, and environmental effects. Hear the world around you.

  • 3D positional audio
  • Reverb & effects
  • Environment-aware
  • Music system
💻

Cross-Platform

Windows, macOS, and Linux. Same features, same performance, same experience on every platform.

  • Windows 10+
  • macOS 12+
  • Linux (x86_64)
  • Mobile planned
