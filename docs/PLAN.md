# VoxelForge Website Plan

## Structure
```
docs/
├── index.html          # Landing page
├── download.html       # Downloads page
├── features.html      # Features showcase
├── screenshots/       # Game screenshots
├── assets/
│   ├── css/
│   ├── js/
│   └── images/
└── _config.yml        # Jekyll config
```

## SEO Strategy
1. **Title**: VoxelForge - C++ Minecraft Clone with Integrated Modding
2. **Keywords**: minecraft clone, c++ game, voxel game, open source, modding
3. **Meta**: Open Graph, Twitter Cards, structured data (JSON-LD)
4. **Performance**: Minified CSS/JS, lazy images, PWA manifest

## Pages

### Landing Page
- Hero with game screenshot
- Features grid (Voxel engine, Modding API, Multiplayer)
- Download CTA buttons
- Latest release links
- Social proof (stars, contributors)

### Download Page
- Platform-specific download buttons
- Release notes
- System requirements

### Features Page
- Technical details
- Modding API docs
- Performance benchmarks
- Comparison table

- Auto-update download links from releases
- Build badges
- Latest commit info
