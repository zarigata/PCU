Build from Source

Prefer to build yourself? Here's how:

# Prerequisites: CMake 3.26+, C++17 compiler, Vulkan SDK

# Clone the repository
git clone --recursive https://github.com/zarigata/PCU.git
cd PCU

# Create build directory
cmake -B build -DCMAKE_BUILD_TYPE=Release

# Build (use all available cores)
cmake --build build --parallel

# Run the game
./build/bin/VoxelForge
