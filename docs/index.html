Quick Start

# Clone the repository
git clone https://github.com/zarigata/PCU.git
cd PCU

# Build with CMake
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel

# Run the game
./build/bin/VoxelForge
