Real gameplay features, not just promises

🏔️

Three Dimensions to Explore

Overworld, Nether, and End — each with unique terrain, structures, and dangers. Plus custom dimensions via mods.

  • 60+ biome types with smooth blending
  • Cave systems, ravines, and underground lakes
  • Villages, temples, dungeons, and strongholds
  • Oceans, rivers, and frozen biomes
⚔️

Survival & Crafting

Full survival gameplay — mine, craft, build, fight. Shaped and shapeless recipes, smelting, enchanting, and brewing.

  • 200+ blocks and 50+ items at launch
  • Inventory, crafting, and equipment system
  • Achievement and statistics tracking
  • Hostile and passive mobs
🧩

Modding API

Two-layer modding: drag-and-drop Lua scripts for quick mods, or native C++ plugins for total control. Hot-reload your mods without restarting.

  • Lua 5.4 scripting with full game API
  • Native C++ plugin system
  • Custom blocks, items, entities, dimensions
  • Per-mod sandboxed environment
