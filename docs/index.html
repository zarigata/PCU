function onPlayerJoin(player)
    -- Welcome message
    player:sendMessage("Welcome to VoxelForge!")
    
    -- Give starting items
    player:giveItem("minecraft:diamond_pickaxe")
    player:giveItem("minecraft:bread", 16)
    
    -- Teleport to spawn
    player:teleport(0, 64, 0)
end

Powerful Features

Everything you need to build your dream voxel game

Vulkan Rendering

Modern graphics API for maximum performance. Multi-threaded rendering, dynamic lighting, and PBR materials.

Lua Scripting

Write game logic in Lua. Create custom blocks, items, entities, and dimensions with a powerful modding API.

Infinite Worlds

Procedurally generated infinite worlds with multiple biomes, structures, and cave systems.

Cross-Platform

Build for Windows, Linux, and macOS. Mobile support coming soon.

Modular Architecture

Clean, modular codebase. ECS-based entity system, plugin support, and hot-reloading.

Resource Packs

Customize textures, models, sounds, and shaders with resource packs. Support for custom block models.
